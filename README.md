# StructureKit

Excelの表や説明文を整理し、Markdown文書として出力するためのMVPです。

## 起動方法

### API

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
uvicorn backend.main:app --reload
```

### Web UI

```powershell
npm install
npm run dev
```

ブラウザーでViteが表示するURLを開きます。APIは `http://localhost:8000`、UIは `http://localhost:5173` で起動します。

初期画面は操作を試せるサンプル帳票を表示します。`.xlsx` をアップロードするとFastAPIがシート・セル・基本書式・結合範囲を読み取ります。Excel読込にはAPIの起動が必要です。

## MVPの範囲

- Excelファイルの解析とシート表示
- ドラッグによる範囲選択、エリア作成・名称/範囲変更・削除・除外
- 要素ごとの編集、並べ替え、表範囲・ヘッダー・行列の除外
- Markdown / HTML / JSONの生成とプレビュー
- ブラウザーへの自動保存、設定JSONの保存・読込
- Markdownプレビュー、コピー、`.md` ダウンロード
- 20MBまでの `.xlsx` を扱うローカルAPI

## 操作方法

### デモExcel

画面上部の「デモExcelをダウンロード」から練習用ファイルを取得できます。
リポジトリ内では `public/demo/StructureKit-demo.xlsx` にあります。

| シート | 試せる内容 | 表の範囲 | 設定例 |
| --- | --- | --- | --- |
| 売上実績 | 通常の横ヘッダー、社内メモ除外、複数表 | A5:G9 / A14:D17 | 商品別売上はG列を除外 |
| 多段ヘッダー | 結合した年度見出し | A5:F10 | ヘッダー行数2、F列を除外 |
| 会社情報 | 縦ヘッダー、行見出し | A5:B10 / A14:D17 | 基本情報はヘッダー行数0、行見出し列数1 |

まず「Excelを開く」でデモを読み込んでください。
その後「出力」タブの「設定JSONを読み込む」で `public/demo/StructureKit-demo.settings.json` を選ぶと、エリアと表の設定例をまとめて復元できます。
全データは架空のサンプルです。

### 範囲の編集

1. シート上の開始セルから終了セルまでドラッグします。
2. 「選択範囲からエリアを追加」でエリアを作成します。左のエリア一覧から編集対象を切り替えられます。
3. エリア内の範囲を選び、「見出しを追加」「説明文を追加」「表を追加」で出力要素を登録します。
4. 文書構造の要素をクリックし、右側で名称・範囲・ヘッダー・出力形式を編集します。
5. 既存範囲を変更するときは、ドラッグ後に「範囲に適用」を押します。右側に範囲を入力して適用することもできます。
6. 下のプレビューを確認し、「Markdown保存」でダウンロードします。

### 表示領域と除外の操作

- 表を選択した状態で、行番号や列記号をクリックすると、その表から除外／復元できます。除外したセルは灰色になり、番号・記号に「−」が付きます。
- 「シートを全画面表示」でシートを画面いっぱいに広げられます。全画面のままシート・エリア・要素を切り替えたり、設定パネルを展開できます。「通常表示に戻す」またはEscで元に戻ります。
- 左右のパネルの右上アイコンで最小化／展開できます。最小化したパネルは細いタブとして残ります。
- シートとパネルの境界をドラッグするとパネル幅を調整できます。パネル幅と最小化状態はブラウザーに保存します。

結合セルの値は展開します。HTMLでのrowspan/colspan維持、エリア分割・統合、大規模シートの仮想スクロールは今後の実装対象です。

## ブラウザーでの回帰確認

EdgeがインストールされたWindows環境で実行します。Playwrightが専用ポートでViteを起動します。

```powershell
npx playwright test
```

実際のxlsxをAPIで解析するテストも、API起動後に実行できます。

```powershell
$env:RUN_API_TESTS = '1'
npx playwright test
```
